# 知识图谱可读优先默认视图设计

## 问题

图谱布局会随模块数量横向扩展。现有样式把 SVG 固定为容器宽度且高度自动，超宽布局因而被整体压缩，节点和关系在很多项目中不可读；最后的响应式规则还覆盖了画布的稳定高度。

## 目标

首次打开时优先保证节点、标签和关系可读，同时保留完整图谱的可探索性。用户可明确切换到全图概览，且筛选、节点列表、来源与键盘操作继续可用。

## 方案

1. 画布使用稳定的可视高度，不再用 SVG 的自然宽高比决定高度。
2. 初始视图采用“适合阅读”：根据画布尺寸和布局尺寸计算缩放值，但不低于可读下限；超出的内容通过平移浏览。
3. 新增两个显式视图操作：`适合阅读` 复位到可读缩放与原点，`查看全图` 按完整布局缩放以提供整体概览。
4. 鼠标滚轮在当前指针位置缩放，缩放范围包含阅读下限和全图缩放；平移仍使用拖拽。
5. 选中节点时将其带入当前可视区域；超宽图显示“可读视图”说明与总节点数，明确用户仍可查看完整图谱。

## 不做

- 不改变图谱数据、筛选上限、后端生成或发布逻辑。
- 不用“始终完整显示”替代可读默认视图。
- 不移除节点列表或键盘选择能力。

## 验收

- 宽布局（至少 20 个模块）首次打开时节点文本可读，画布不再因整图压缩而接近零高度。
- `查看全图` 可展示完整布局，`适合阅读` 可恢复默认阅读缩放。
- 选中画布或列表节点后，该节点进入可视区域。
- 1440px、768px、390px 宽度下没有页面级横向溢出，画布可平移且控制按钮可达。
- 保持筛选、关系选择、键盘节点导航和现有来源面板行为。
